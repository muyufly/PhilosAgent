# 可修订哲学系统原型

本目录把哲学作为相互关联的立场和论证来编写，供 Agent 解释情境、权衡选择及修订自身认识。它仍经文本进入模型；是否实际承担了这些功能，需要后续行为实验，不能由文件格式或“系统”这个名称保证。

[dialectical-v1.json](dialectical-v1.json)是第一份**辩证取向的系统原型**，尚未经过真实模型验证。它采用现有 seed schema，因此当前 `init --seed-file` 可以加载。六个长条目是论述段落和引用标识，不是六个执行阶段：

| 标识 | 讨论的核心问题 | 与其他部分的联系 |
|---|---|---|
| ONT | 对象、关系、条件和变化如何被理解 | 为认识与具体分析提供前提 |
| EPI | 什么构成认识与理由，实践有什么作用 | 从对象与描述的区别出发，连接认识和行动 |
| MET | 理论与经验怎样相互约束，何时改变概念 | 接续 ONT/EPI，也保留方法适用性的不确定 |
| VAL | 求真、成效、成本和责任如何相处 | 明确价值选择不能从对象描述直接推出 |
| ACT | 有限认识下如何理解行动和选择 | 综合 EPI 与 VAL，不预写具体选择 |
| REV | 系统怎样接受批评、保持连续并发生重组 | 回用于上述所有部分，区分事实、方法与价值的修订理由 |

每一部分包含立场、理由或关联、适用限制及开放问题。没有把所有张力预先解决，也没有规定唯一正确的后继哲学。ONT/EPI/MET参考客观条件、认识与实践、具体分析等思想；VAL/ACT/REV中面向受托 Agent 的解释是本项目构造，不声称复原任何原著的完整体系。

四项[公共方法资源](common-methods.json)提供分解、依据对应、局部诊断及经验适用性检查；[组合加载版本](dialectical-with-methods-v1.json)包含六段系统正文及四项资源，确保两者都进入当前初始化。它们是可直接采用的文本方法，尚不是注册为工具的函数。原 [v2 方法卡](../v2/README.md)另作参考和对照，不会被自动加载。世界观可以帮助 Agent 选择、解释、组合或修订方法；完整系统的效果不能以“逐条服从方法卡”衡量。第一版不新增图数据库、形式逻辑证明器或固定的“先哲学分析再行动”流程。

## 可用程度

在仓库根目录执行下面的命令仅建立隔离运行，不调用模型：

```powershell
.\.venv\Scripts\python.exe -m philoagent init dialectical-system-draft --seed dialectical --seed-file seeds/systems/dialectical-with-methods-v1.json
```

它会冻结完整初始文本。组合文件按“系统六段＋公共方法四项”的固定顺序从两份源JSON构造，当前兼容层把两者都存入同一Φ列表。正式实验需将公共方法以相同方式置于各组普通方法记忆中，以免误把资源差异当哲学效应；这项适配尚未实现。现有候选机制可以通过 `orientation_items` 替换文本并由获胜后代继承，**但这只证明可读写和传递**。命题关联尚由自然语言表达；系统没有实现论证检查、修订影响追踪、新的连续决策实验或独立的低成本哲学更新入口。

作为后续实现要求，修订记录需要指向受影响的段落、已有经历、保留／改变的理由及对后续行为的预期；不需要模型披露隐藏推理。段落 ID 只是审计引用，不能用“出现了某个 ID”证明因果作用，也不能用谱系 hash 改变代替内容改变。

## 理论与研究边界

概念参考[《实践论》原文英译](https://www.marxists.org/reference/archive/mao/selected-works/volume-1/mswv1_16.htm)与[《矛盾论》原文英译](https://www.marxists.org/reference/archive/mao/selected-works/volume-1/mswv1_17.htm)。该原型不等于完整辩证唯物主义，不把任何哲学争论写成已经解决的工程事实，也不把一次任务失败当作对整个世界观的证伪。

关于可修订信念与 Agent 记忆的研究边界，见[研究笔记](../../research/revisable-philosophical-system-20261029.md)。关于如何检验它真正参与决策、修订和迁移，见[方案 v0.0.5](../../planv0.0.5.md)。先把一套系统写到可审阅和可检验，再扩展批判理性等完整体系；当前两者不能被标为已有同等完备的系统版本。
