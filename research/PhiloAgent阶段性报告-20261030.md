# PhiloAgent 阶段性研究报告

面向持续学习智能体的可修订哲学状态与开放任务实验

报告日期：2026 年 10 月 30 日  
数据截止：2026 年 10 月 30 日 10:29:21，香港时间

## 摘要

PhiloAgent 围绕一个具体问题展开：智能体能否在积累任务经验、改进记忆工具的同时，保留并修订指导其理解问题、判断证据和选择行动的方法立场？我们在 MemEvolve 的原生学习与演化流程上，引入与候选系统绑定的哲学状态，完成了状态初始化、继承与修订、跨轮加载、开放任务评分，以及本机网页、命令行和 Python 接口的实现。

当前阶段形成了三类成果。第一，建立了“哲学状态、普通经验、记忆程序”协同工作的可运行原型，并在真实调用中观察到哲学文本修订及其跨代保留。第二，构建了覆盖人文、社会与商业任务的三组对照方案，保留候选生成、验证、同题比较与独立留出的完整流程。第三，获得首个完整的人文领域配对结果：在同一组四道留出题上，完整 PhiloAgent 的质量均分为 **91.550**，原生基线为 **87.075**，平均高 **4.475 分**，其中三题提高、一题下降。

三个领域分别形成 156、133 和 114 份完成执行记录。社会领域的固定与可修订哲学组在初始学习和首轮演化后的同题比较中均出现正向均差，但唯一已完成的固定组留出题低于基线；商业领域首轮演化后的两道新题上，两种哲学配置分别比基线高 1.35 和 1.45 分，尚未完成哲学组留出评估。各领域的现有学习与留出结果均纳入下文，按相同阶段和题目比较。[3,10]

这一结果为完整方法在开放分析与写作任务中的应用提供了初步正向信号。当前完成的是一个领域、一次重复的完整配对，尚不能据此确认跨领域稳定收益或哲学修订的独立因果作用。项目现阶段的主要贡献是可检验的方法建模、可运行的系统实现，以及包含正向结果、负向案例和真实运行限制的实验材料。[1–5]

## 一 研究问题与方法定位

持续学习智能体需要处理两类变化：一类是“过去经历过什么”，另一类是“现在应如何理解和使用这些经历”。PhiloAgent 将后者作为显式、可修订的研究对象，希望使方法立场能够随任务反馈被保留、调整，并由后续任务继续使用。

在实现中，我们区分三个状态。普通经验 **M** 保存任务经历及可检索的经验；记忆程序 **P** 实现经验的组织、检索和摄入；哲学状态 **Φ** 则以自然语言表达对对象、证据、方法、价值、行动和自我修正的基本立场。当前 Φ 是面向智能体的工程化文本表示，其价值由后续任务表现检验。

项目复用 MemEvolve 的候选生成、验证和选优框架，主要增量是把 Φ 接入候选生命周期，并扩展到开放作品的连续质量评估与应用入口。这里的持续学习发生在外部经验、程序和方法状态层面，不涉及基础模型权重训练，也不将已有的上游演化算法列为自研成果。[1,6]

## 二 已完成的系统工作

### 1 哲学状态随候选系统继承与修订

我们实现了独立的 Φ 状态及其版本记录。单次任务执行时，Φ 保持只读；创建新候选时，系统可以继承父代内容、提交修订，或显式清空。候选胜出后，其程序和哲学状态进入下一轮任务。初始化、生成、运行和恢复环节均保留身份与哈希信息，便于核对实际加载的是哪一版本。

这一设计使方法立场具有可追踪的生命周期。真实人文谱系中，首轮胜者 Credence Lattice 修订了初始 Φ，第二轮胜者 Praxis Reliquary 又继承了这份修订版。修订内容涉及证据强度、重复信息与独立证据的区分，已进入后续任务输入。[2,4]

### 2 将开放任务质量接入完整学习流程

我们把人文评论、社会分析和商业方案适配到原生任务执行器。系统围绕真实作品完成作答、评分、经验摄入、候选程序生成与验证，再让入围候选回答相同题目并选择胜者。连续质量分直接参与选优，保留分维度评分与理由。

完整流程可以概括为：**当前 P、M、Φ 执行任务 → 作品评分与经验摄入 → 生成并验证候选 → 同题比较与终选 → 获胜状态进入下一轮 → 冻结训练状态完成留出评估**。留出阶段每题使用独立快照，作品与评分不再摄入训练记忆。[1,2]

### 3 建立可核对的运行与恢复机制

长流程会受到网络中断、接口额度、生成代码兼容性和评分格式错误影响。我们实现了按阶段保存、复用已完成作品与付费响应、保留失败记录、区分费用结算和作品完整性等机制。空正文、截断和未恢复的核心请求故障不会仅因存在数值评分就被算作完整交付。

例如，一份 75.4 分的社会任务在摄入中断后，通过复用两份已有成功响应完成原生摄入，答案与评分保持不变，该次本地恢复新增模型请求为 0。这验证了在已有证据充分时恢复阶段结果的能力，也降低了重复付费作答的需要。[5]

### 4 提供可使用的智能体入口

项目已实现本机网页、命令行与 Python `Agent` 类，支持导入初始哲学系统、提交文社商任务、保存作品与评分、积累经验，以及手动演化和隔离评测。应用状态保存在独立目录，便于将交互使用与实验记录分开管理。当前交付形态是依赖仓库与模型服务配置的本机原型。[6]

上述成果形成了明确的自研边界：上游提供演化框架，我们提供哲学状态接入、开放任务适配、评测与恢复工程，以及面向使用者的统一入口。

## 三 实验设计与完成范围

### 1 三组完整方法对照

| 组别 | 哲学状态 | 普通经验与记忆程序 | 比较目的 |
| --- | --- | --- | --- |
| N 原生基线 | 无独立 Φ | 正常学习与演化 | 提供原生系统参照 |
| F 固定哲学 | 加载并固定同一初始 Φ | 正常学习与演化 | 观察引入固定系统的整体作用 |
| R 完整 PhiloAgent | 从相同 Φ 出发，允许随候选修订 | 正常学习与演化 | 观察完整方法的表现 |

N 仍拥有普通记忆及原生先验，不是“无记忆”条件。R 与 N 的差值衡量本轮完整方案的整体表现；只有完成同条件的 R 与 F 对照，才有条件进一步讨论允许哲学修订的额外收益。三组共享模型、题目与评分规则，实际程序、经验和计算量可以随演化产生差异。[1]

### 2 数据与评价

实验使用固定版本 WritingBench 中的 36 道中文原题，覆盖人文、社会与商业三个领域，每域 8 道学习题和 4 道留出题。题目按内容和任务类型选择，选择时未使用模型成绩；原始题干、材料及 checklist 保留。计划规模为三领域、三组、三次重复，共 27 条谱系，每条执行两轮学习与演化。[1]

作品按领域五个维度评分，再按既定权重汇总为 0–100 分。Judge 通过独立调用接收题目、任务要求和作品，不接收组名、Φ、反思记录或成本。Actor 与 Judge 均使用配置的 `deepseek-flash`，因此“独立调用”不等于独立模型家族；这些分数是本项目的质量指标，不是 WritingBench 官方榜单成绩。[1,2]

## 四 主要结果与分析

### 1 三领域初始学习的完整同题对照

三次重复的初始阶段共完成 54 份作品，构成 18 个“相同领域、相同重复、相同题目”的 N/F/R 三组配对，每域六个。下表覆盖全部已完成的初始配对，均分为百分制；“配对数／原题数”区分重复作答与独立题目。[10]

| 领域 | 配对数／原题数 | N 原生基线 | F 固定哲学 | R 完整方法 |
| --- | --- | ---: | ---: | ---: |
| 人文 | 6／3 | 86.750 | 88.150 | 86.700 |
| 社会 | 6／6 | 77.000 | 82.033 | 82.567 |
| 商业 | 6／4 | 71.433 | 83.600 | 86.767 |

此时三组使用相同的基线记忆程序，F 与 R 的初始 Φ 相同，尚未发生候选哲学修订；第二道题已经继承第一道题的普通学习。因此，这张表反映初始配置下的学习表现，F 与 R 的差异不能解释为修订收益。

人文 R 与 N 的均分基本持平。社会 F 与 R 相对 N 的均差分别为 +5.033 和 +5.567 分，两组均在六个配对中五高一低，是跨初始任务的正向观察。商业均差受 N 的一次零交付强烈影响：WB0100 的 N 实际仅输出 `answer`，该 0 分在主结果中保留。仅作敏感性检查，去掉这一整个三组配对后，其余五个商业配对的 N/F/R 均分为 85.720／84.720／85.980，差异显著收窄。这说明不能把商业初始均值差直接视为方法带来的普遍提升。

### 2 人文完整配对出现正向信号

人文 N 与 R 均完成两轮原生学习和四题独立留出。逐题核验确认，两组使用相同题面、题序和冻结的任务及模型协议；八份评分均对应各自完整的模型评审回执。[2]

| 留出任务 | N 原生基线 | R 完整方法 | R 减 N |
| --- | ---: | ---: | ---: |
| WB0372 《三体》书评 | 94.1 | 90.6 | -3.5 |
| WB0388 《挪威的森林》读后感 | 74.2 | 86.6 | +12.4 |
| WB0596 《喜福会》书评 | 89.6 | 95.3 | +5.7 |
| WB0930 《消失的她》影评 | 90.4 | 93.7 | +3.3 |
| 四题均分 | **87.075** | **91.550** | **+4.475** |

完整方法在四题中的三题高于原生基线，最大差值出现在《挪威的森林》任务；《三体》任务则低 3.5 分。这表明当前增益具有任务差异，不能概括成所有人文题都会提高。这里的 4.475 是百分制上的分数差，不是正确率提升 4.475 个百分点。

这组结果的意义在于：正向差异出现在完整学习之后、未用于候选选择的留出题上，且对应的 Φ 修订和跨代传递已经真实发生。不过，两组的程序与普通经验也随演化不同，当前只能将差值归于完整配置的比较；单次重复、四道题与同源模型评审也限制了外推强度。

进一步比较五维均分，可以看到增分主要来自分析内容。下表各维为 0–5 分，权重分别为 20%、30%、25%、15%、10%。

| 阐释 | 4.500 | 4.750 |

模型评语认为，R 在《挪威的森林》任务中对人物和主题的细读、解释边界处理更充分；《三体》任务则以一般科研共同体经验替代了题目要求的具体个人经历。评语认可后者的坦诚，同时扣除了任务适配分，提示角色写作要求与避免虚构个人经历之间存在评价张力。这些评语解释了评分者关注的差异，尚不能代替人工核实。

商业领域已验证完整基线流程能够执行，哲学配置在两道后续学习题上取得小幅正向均差。其留出收益仍未确定，初始阶段的大幅均差也不构成稳定提升的证据。

### 5 早期探索明确了后续检验重点

前期 WebWalkerQA 七格探索验证了 Φ 修订、候选程序执行和后续加载等机制，但工程四格在四道留出题上分别为 0/4、1/4、1/4、0/4，未支持稳定性能收益。七格中的五格来自原始完整执行，另两格来自已披露的补充恢复；所有组间差异集中于同一道题。该轮主要作为机制与评测诊断证据保留。[7]

后续压缩试跑虽然产生了 324 个评分位置，但削减了候选程序验证和完整记忆流程，并存在输出截断与评分方式混用。对 255 份新生成作品的审计发现 114 份最终响应触及输出上限；108 份留出中有 56 份。该批数据退出正式主比较，用于说明短流程和非空正文检查不足以替代完整方法验收。[5,8]

## 五 资源经验与证据边界

排除压缩诊断分支后，原生历史模型 SDK 请求累计为 18,465 次，其中 403 次请求的用量仍未知，已确认用量为 301,742,425 tokens。此范围包含失败、恢复与未完成谱系，不含另行记录的网页搜索和抓取 HTTP 请求，不能直接作为 403 份完成作品的纯成本。账本没有可核实的实际货币金额，因此不据此折算人民币或美元费用。[9]

| 领域 | 历史 SDK 请求 | 已确认 tokens | 用量未知请求 |
| --- | ---: | ---: | ---: |
| 人文 | 6,343 | 80,344,357 | 116 |
| 社会 | 6,008 | 111,595,426 | 146 |
| 商业 | 6,114 | 109,802,642 | 141 |
| 合计 | **18,465** | **301,742,425** | **403** |

资源分析表明，应优先优化反复传入的上下文和学习调度。原生历史已确认 tokens 中，Actor 占 43.395%、演化分析占 31.504%、记忆检索占 17.948%，三者合计约 92.85%；输入占全部确认 tokens 的 88.437%。这一分布为后续控制长上下文开销提供了具体方向。[9]

对人文四题留出，N 的已确认用量为 1,038,644 tokens，R 为 2,138,271 tokens，R 约为 N 的 2.06 倍。当前正向质量差异伴随更多实际计算用量，因此尚未建立效率优势。这是留出执行的用量比较，不包含两组完整训练成本。[9]

当前各组完成度和恢复历史不同，尚不适合用累计消耗判定某组更省。额度中断、真实作答失败和完整作品质量也应分别解释：例如商业基线学习阶段曾真实提交仅含 `answer` 的答案并得到 0 分，该失败保持原样；未完成的其他任务则没有被补成零分。[4,5]

本阶段结论的主要边界集中在三点。首先，完整方法仅获得一个领域、一次重复的四题配对，尚缺完整固定哲学对照和更多重复。其次，质量主要由同源模型评审，元数据隐藏可以减少直接的组别偏向，但仍需人工抽查引文真实性与论证质量。最后，Φ、M、P 共同变化，现有实验支持比较整体方法，尚不能把分数变化精确拆分为每个组成部分的贡献。

这些边界不影响将现有成果作为阶段性交付：系统已实现，真实状态演化已有记录，小规模留出结果也足以提出具体、可继续检验的研究判断。

## 六 阶段结论与成果价值

PhiloAgent 已完成从方法构想到可运行系统、再到真实开放任务评估的初步闭环。项目的价值首先体现在将哲学立场变成候选系统中可继承、可修订、可核对的状态，并将其放入普通经验与记忆程序共同演化的流程中；其次体现在提供了任务、评分、恢复与应用入口相互衔接的实现，使后续研究可以从已有系统和记录继续开展。

实验层面，首个人文完整配对取得平均 4.475 分的正向差异，同时保留一题下降、学习阶段反向表现与早期无稳定收益的结果。因此，当前最合适的判断是：**可修订哲学状态已经具备可运行、可传递和可评价的实现形式；完整方法在小规模人文留出任务上显示应用潜力，其稳定性及独立作用仍有待更多证据。**

三领域共同构成了当前阶段的经验基础：人文提供首个完整留出正向配对，社会提供初始及后续学习阶段的正向观察和一项留出反例，商业提供小幅同题差异、零交付敏感性与完整基线。这样的结果分布支持继续研究方法状态如何影响具体任务，同时表明其作用需要按领域与阶段理解。

在当前时间和预算下，可以将本阶段定位为“方法与系统原型完成，获得初步实验信号”。近期工作可集中于利用已有作品开展人工复核、整理演化案例和演示材料；新的跨域配对与重复实验留待资源允许时推进。
