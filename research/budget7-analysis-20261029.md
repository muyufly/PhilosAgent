# PhiloAgent 精简实验分析报告

**状态：七格均已接纳，实验调用已结束。** 2026 年 10 月 29 日，香港时间。原五条完整结果与两项明确披露的补充合并分析，原始失败记录保留。

当前证据已确认，三组初始哲学及空原则对照均按各自配置加载；哲学原则可以在题间修订，记忆工具代码可以生成、验证、执行并由后续任务加载。任务表现方面，工程四格为 0/4、1/4、1/4、0/4，未观察到共同演化收益；额外重复的差值还出现反向。当前不能据此判断某种初始哲学更优。

## 实验问题与范围

本实验将初始哲学原则记为 Φ，普通任务经验记为 M，记忆 provider 的代码与非路由配置记为 P。Φ 在单道任务内固定，候选创建时可以继承、增加、修订或清空；候选获胜后，下一轮任务读取它的 P 与 Φ。所有条件均保留 M 的日常检索和经验摄取。

Φ 在当前实现中被操作化为自然语言方法准则列表。准则条目增减可以核验，不能直接代表完整哲学理论或认识论体系发生了改变。

按预算调整后的七格矩阵，engineering 保留 P 与 Φ 两个开关的完整四格；dialectical、critical、none 各保留共同演化一格。预算调整时按序号统一固定 `r00`，没有按成绩更换重复；其他已完成重复作为稳定性附录。原 48 条、三重复计划已经停止；本次七格是运行中调整后的探索性比较，不是事前预注册的确认性实验。

| 初始条件 | P 演化 | Φ 演化 | 主比较的作用 |
|---|---:|---:|---|
| 工程方法 | 关 | 关 | 普通经验持续学习的基准 |
| 工程方法 | 关 | 开 | 固定 P 时观察 Φ 修订 |
| 工程方法 | 开 | 关 | 固定 Φ 时观察 P 演化 |
| 工程方法 | 开 | 开 | 观察共同演化及四格交互 |
| 辩证方法 | 开 | 开 | 共同演化下的初始化比较 |
| 批判理性 | 开 | 开 | 共同演化下的初始化比较 |
| 无额外初始哲学 | 开 | 开 | 初始 Φ 为空的对照 |

`none` 只表示独立 Φ 列表初始化为空。各组仍有同一原生记忆机制：基线 provider 的空存储会注入五条战略经验和两条操作经验。因此，它不是无记忆或无先验条件。

本次使用的三组初始原则都为四条。工程组强调明确约束、分解步骤、检查材料及修订无效方法；辩证组强调具体条件、阶段变化、制约关系及实践检验；批判理性组强调可修订猜想、竞争解释、反驳材料及放弃失效解释。这些是仓库已有种子的操作化定义，本次没有临时增加另外两种哲学。

后续可以修改 `seeds/*.json` 来定义新运行的 Φ₀；已有运行保留自己的冻结初始化。题间候选通过 `orientation_items` 修订当前 Φ，省略该字段时继承，非空列表替换，空列表清空。不要直接改写已有谱系文件绕过完整性检查。本报告按原 manifest 中的种子复算，未来修改默认种子不会改变本轮历史定义。

## 模型与评测方法

任务、分析、生成和裁判均使用配置锁定的 `deepseek-flash`，关闭 thinking；搜索和抓取使用 DeepSeek Search 与 Fetch，复用模型密钥。任务端沿用 Flash Searcher，演化和选优沿用 MemEvolve。自动演化的代码对象是记忆 provider，搜索和抓取实现不参与代码演化。

每条运行目标为两轮演化，每轮一个发现任务、一个候选生成名额。父代与通过验证的候选在相同发现题上比较，再评测发现题与下一道开发题；原生选优首先比较正确率，再以 token 用量打平。四道开发题用于演化，终态确定后评测共同的四道留出题，`max_steps` 参数设为 6。原生日志还可能包含计划和强制结束请求，不能把这个参数当作六次模型请求或六条日志记录的绝对上限。

开发与留出任务的根 URL 分组互斥。各次父代与候选比较先重置独立存储，再按相同顺序重建已完成开发轨迹；已完成主格的比较双方 warmup 哈希一致。不同实验条件会形成不同历史轨迹，生成架构自身的冷启动也可能不同，因此这是整体过程比较，不能把差异单独归因为某个检索函数或原则文本。

留出阶段关闭 `take_in_memory`，不摄取留出题轨迹或标准答案，但保留原生检索管理的副作用。例如 LatticeCortex 在检索时更新使用次数并保存状态，后续题的检索可能受先前查询影响。四题按固定顺序评估，不将它描述为四次完全隔离、M 全程只读的试验。

|---|---:|---:|---|---:|---|

工程共同演化组的 **0/4 是补充重放分数**，不是将原失败填零。补充规则在发生技术失败后确定，故补充矩阵只能用于披露修订后的探索性比较，不能回写成“原协议七条全部成功”。

## 工具和哲学的真实修改证据

七格的初始快照均与设计中锁定的种子文件及原则内容匹配，基线代码有真实加载和提供记忆的记录。首个发现题的请求审计在三种非空初始化中都发现了当前 Φ 的全文；none 对应空列表。分析和生成请求也核对了各自父代的 Φ：工程仅 Φ 可变组的生成输入由四条变为五条，none 由空变为五条。由此可以确认 Φ 已进入任务与工具生成上下文，能够作为修改依据；这不证明模型始终遵循它，也不构成 Φ 对生成代码的独立因果证据。

审计中 `role=actor` 的作用域覆盖整道任务，部分工具摘要请求会继承该标签，所以不能声称每条标为 actor 的请求都含 Φ 全文。完整命中、未命中、源码和请求行哈希保存在[初始 Φ 审计](budget7-initial-phi-audit-20261029.json)。

| 条件 | 两轮候选与选优 | 内容变化和后续加载 |
|---|---|---|
| 工程：P 固定且 Φ 固定 | 两个别名候选均创建并执行 | P 字节与 Φ 内容均不变；provider 名称变化不算修改 |
| 工程：仅 Φ 可变 | 两轮均选中修订后的候选 | Φ 为 4→5→6 条；第二轮任务实际加载第一轮的五条原则，P 及有效配置保持固定 |
| 工程：仅 P 可变 | 基线→FacetLoom→LatticeCortex，两轮均选中新代码 | 第二轮任务实际加载 FacetLoom，Φ 始终保持初始四条 |
| 工程：P 与 Φ 均可变 | 基线→LatticeWeave→Cinderglass，两轮开发均选中新代码 | P 已修改并执行；Φ 两轮均保持初始四条，重放终态也匹配该版本 |
| 辩证：P 与 Φ 均可变 | 第一轮修订候选落选，第二轮 CausalTrigger 胜出 | 最终 P 改变；Φ 最终为原四条，修订候选的执行不等于修订进入后代 |
| 批判理性：P 与 Φ 均可变 | 第一轮新代码落选，第二轮候选被拒绝后继续父代日程 | 最终保留基线 P 与原四条 Φ，不能将生成尝试算作获胜修改 |
| 无初始：P 与 Φ 均可变 | 第一轮 CadenceWeave 胜出，第二轮候选落选 | P 已改变，Φ 为 0→5→5 条；第二轮与终态实际加载第一轮版本 |

辩证组第一轮 DialecticSlot 修改 P，并修订第四条 Φ（条数仍为四），候选确实执行但父代胜出；第二轮 CausalTrigger 改变 P、保留初始 Φ，获胜并由终态加载。其最终 Φ 没有改变。无初始组第一轮 CadenceWeave 改变 P，Φ 为 0→5 条并获胜；第二轮 LatticeTrace 保留这五条，执行后落选，终态仍为 CadenceWeave。

批判理性组第一轮 CausalLedger 的新代码确实执行，Φ 逐字继承四条；终选双方均为 2/2 时，候选的每题平均 tokens 为 67,149.5，高于父代的 62,288，因此保留基线父代。第二轮保存的候选在创建前被拒绝。不能把生成过文件或允许演化写成终态已修改。

仅 Φ 可变组新增的两条原则分别要求预判年份、归属和类别等来源冲突，并规划独立验证路径；优先采用一手权威来源，对数据集镜像或聚合摘要标注证据强度。它们属于从轨迹产生的方法性追加，不能仅凭条数增加认定原则质量改善。

仅 P 可变组先采用任务分面、目标证据账本以及原则、步骤、规避三类记忆；下一轮改为节点与关系边，结合关联扩展、使用反馈和时间衰减排序。共同演化组增加失败反例、负向反馈、短期增量呈现和同族记忆合并。这些机制已在实际加载的源码中确认；运行证据证明 provider 被执行，尚不能证明每个新增分支都实际触发。

无额外初始哲学组在开发阶段将 Φ 从零条变为五条，并由下一轮任务与终态实际加载。其中直接行动、精确遵守格式、标注推断证据、优先服从明确指令等条目，与各组共有的原生冷启动经验高度近义；新增列表的来源仍可能包括 M 中已有准则的显式化。其第五条要求采用目标明确的多跳检索、在无结果路径上及时转向。终态成绩为 1/4，不能据此称为“从无先验自发创生哲学”或建立无初始哲学更优的结论。

哲学变化先比较原则文本列表，再人工检查差异；脚本的列表不等检查不等同于自动语义评价。代码变化按实际源码字节及结构判断。provider ID、父代 ID 或包含这些元数据的快照哈希改变，都不能替代内容变化证据。候选提议、候选执行、获胜和下一轮加载分别记录。

## 额外重复揭示的不稳定性

预算调整前，固定 P 的两组已完成三次重复，结果如下。该表保留为补充结果，不替换主比较预定的 `r00`。

| 重复 | Φ 固定 | Φ 可变 | 可变减固定 |
|---|---:|---:|---:|
| r00 | 0/4 | 1/4 | +25 个百分点 |
| r01 | 1/4 | 0/4 | −25 个百分点 |
| r02 | 1/4 | 0/4 | −25 个百分点 |
| 三重复描述均值 | 16.7% | 8.3% | −8.3 个百分点 |

`r00` 的正差在另外两次重复中反向。三次重复仍然是同四道题的多次运行，不是十二道独立题；题序随重复变化，且原生检索存在状态副作用，差异也包含题序和记忆路径变化，不能仅归于生成随机性。这个观察直接限制了“Φ 修订已经有效”的结论；本轮较可靠的发现是状态修订和工具接入成立，而任务收益需要更多证据。

## 成本和中断处理

削减前的可核验历史下界为 34,751,743 chat tokens、6,668 次 SDK 尝试和 3,801 次搜索或抓取请求。该下界仍缺少部分早期网页验收的 chat usage 和未落盘在途请求；它不代表已确认账单金额。

本次追加共享阈值为 14,220,327 chat tokens、2,666 次 chat 请求和 1,616 次网页请求，最多两条运行并行。任一阈值到达后停止发起新请求；响应返回后才结算实际 tokens，已放行的在途请求可能造成少量尾部用量。未知 usage 和配额拒绝会阻止发布完成结果。失败尝试也计入用量，重放不会清零账本。

追加计量从精简范围启动时开始，包含四条继续或新启动运行及两项补充的实际调用；三条已经完整的工程结果直接复用，其旧用量属于历史部分。不能将追加总量除以七，解释成七次从头独立运行的平均成本。历史部分还包含早期验收与被停止的实验，不等于本次七格的独立账单。

将历史已知下界与本次精确追加相加，可确认累计至少 **41,178,276 chat tokens、8,102 次 SDK 尝试、4,689 次网页请求**。该总数仍是含早期测试的可核验下界，缺失用量未填零，也没有据此推算金额。

工程共同演化组的留出中断属于运行失败，原分数保持未知。补充只允许一次：冻结同一终态 P、Φ、配置和演化状态，在独立副本中用同四条已完成开发轨迹重建 M，再按相同顺序完整重跑四道留出题，不拼接原先部分评测，不重新生成候选，不挑选较高分结果。该重建不保证 M 的字节或随机状态完全一致。重放完成后，前后 P、Φ、配置和演化状态哈希一致，原失败的 303 个文件均保持不变；重放使用 90 次 chat、79 次网页请求和 375,695 tokens，全部计入同一追加账本。它验证终态的可运行性，没有修复或查明原解析错误的完整成因。

批判理性组第二轮的生成代码使用 `__import__("math")` 计算使用频次，触发固定的动态导入禁令。它在创建和执行前被拒绝，不提供该候选的任务效果证据。补充日程保留该拒绝，以空的有效子代集合使用父代继续原生比较和终态评估，不替换导入写法、不重抽候选、不重复分析或生成。补充完成后父代 P、Φ 和有效配置不变，原失败的 278 个文件均保持不变；新增 158 次 chat、119 次网页请求和 712,292 tokens。该 0/4 是拒绝候选后继续父代的结果，不能解释成被拒绝代码运行后的成绩。

复用的工程共同演化前缀还包含一次早期候选标识符校验失败后的生成重试，两轮累计三次生成请求。本次预算启动器没有重复这次生成，但不能把整条历史描述为严格只有两次生成响应，也不能假定各格的实际生成尝试数完全相同。

## 结论的适用范围

工程四格可计算本次单重复下 P 与 Φ 的条件差和交互，其余三种初始化只允许比较共同演化条件，无法分别归因于 P 或 Φ。共同留出集仅四道题，一道题就改变 25 个百分点；单重复不足以稳定估计方差或判断学派优劣。

本次使用同名模型作为 actor 和裁判，尚未独立人工复核。不同初始化在不同批次访问实时网页，返回内容、生成随机性和裁判波动也可能影响分数。实验未进行共同 Φ、共同 M 的终态代码回放，因此不能从整体过程差异直接推出 P 本体或初始哲学的独立因果贡献。

原则修订还会同时改变提示的内容、长度和语言。本次没有等长度的普通方法提示或打乱原则对照，无法进一步区分哲学内容、额外任务指令和提示长度各自的作用。

下一轮应先人工复核四题的题意、原文时间与金标，并固定裁判口径；为工具调用解析失败保存必要的原始响应，复现后再修复；将无效候选的拒绝和父代继续规则在运行前统一定义。成本方面优先压缩外层分析的重复长上下文，并用带哈希的完整检查点复用已完成工作。之后再用按任务配对、批次平衡且有更多独立题目的设计验证收益，保留全部重复与失败率。
