# 智能体演示数据

`initial-philosophy.md` 是可直接导入的初始哲学系统。Markdown 文本作为完整的一条初始取向保留，不经过模型改写；也可使用兼容的 `schema_version: 1`、非空字符串 `items` JSON。

`development.jsonl` 包含六道原创开发题，文、人社和商业每域两题，可用于单题学习或原生演化。每轮原生演化需要四道开发题。`evaluation.jsonl` 包含另外六道原创评测题，每域两题，标有 `split: evaluation`，只用于独立评测。两组材料、问题和 ID 均不同。

所有人名、机构、文本和数据均为本项目为演示自编的虚构材料。题目要求仅使用给定材料，不联网检索；模型调用仍需配置服务。它们用于演示产品流程与评分可复现性，不作为正式实验数据，不支持直接推断普遍有效性或统计显著提升。

默认评测比较同一题上的初始智能体与当前智能体，使用现有匿名分领域五维 rubric 计算连续 0–100 质量分。每题、每个比较对象均从冻结的哲学取向、原生提供器及记忆副本开始，作品和评分不写入智能体记忆。任何已用于该智能体学习或演化的同 ID、同公开内容任务都会被拒绝用于评测。

报告同时保存每题作品、评分依据、失败、缺失评分与用量未知状态。平均差值仅纳入双方均完成且评分合法的题目；单侧有效结果仍独立保留。失败和未知用量不按零填充。报告输出为操作目录内的 `report.json` 和 `report.md`，不触碰正在运行的正式实验。
